# IT481 Unit 7 Benchmarking

This project benchmarks three sorting approaches:

1. Bubble Sort
2. Optimized Bubble Sort
3. Quick Sort

The program creates three random data sets:

- Small: 10 items
- Medium: 1,000 items
- Large: 10,000 items

The main file to run is:

`BenchmarkSort.java`

The program prints elapsed time in nanoseconds for each sorting method.
